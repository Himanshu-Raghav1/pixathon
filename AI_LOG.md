## 2. Key prompts

### Prompt 1 — Requirements analysis & Architecture
Prompt: Build "GLITCH — See What Others Miss", a polished playable browser puzzle game with 3 rounds: Spot the Glitch, Reality Check, What Changed, <30s target, dark electric-lime/violet theme, responsive, keyboard accessible, restart without reload, optional analytics.
Result: Formulated architecture using pure Vanilla HTML5/CSS3/ES6 with inline SVG rendering and zero external dependencies to ensure 100% portable browser execution. Confirmed user preferences for retry scoring and pure visual presentation.
Verification: Inspected runtime environment, confirmed zero-dependency standalone HTML/CSS/JS is ideal.
